# Reference photos (optional)

In **Photos** mode, each P-position row shows a small reference image. By default it's a drawn golfer figure.

To use your own reference photos instead, add them to this folder named exactly:

```
P1.jpg  P2.jpg  P3.jpg  …  P10.jpg
```

Any position with a matching file shows your photo; the rest keep the drawn figure. Portrait photos (about 5:6) fit best. Only use photos you have the rights to.
